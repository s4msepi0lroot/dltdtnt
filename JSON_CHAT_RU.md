# JSON-реплики — реализованы в MVP-3

## Что видят игроки

```text
<НикИгрока> Твой текст
```

Без префикса `[Бред]`. Ник берётся из серверного GameProfile, а не из JSON. Это визуальный формат обычного чата, но технически серверное системное сообщение. Оно не получает поддельную криптографическую подпись игрока и не означает ручной ввод человеком. Фильтры/плагины именно подписанного player-chat могут обрабатывать такие сообщения иначе.

## Файл

Сервер/интегрированный singleplayer-server: `config/vitalstages/delirium_phrases.json`. Установка в runServer создаёт файл относительно рабочей папки того запуска, например run/config. На клиентских компьютерах подключённых игроков отдельные списки не нужны.

```json
{
  "version": 1,
  "phrases": [
    "Кто это сказал?",
    "Мне показалось, там кто-то был..."
  ]
}
```

Это только пример; поставка и автоматически созданный файл содержат пустой массив, чтобы мод не публиковал придуманные фразы. Заполни phrases своим текстом. При пустом списке молчит. Шаблон: examples/delirium_phrases.json.

Ограничения: UTF-8 (BOM допустим), 64 KiB, максимум 128 строк, 1–160 Unicode code points на фразу. Краевые обычные пробелы убираются, дубликаты удаляются с сохранением порядка. Нет комментариев, повторяющихся ключей, неизвестных полей, хвоста после объекта. Version — число 1. Запрещены управляющие символы, переносы строк, коды §-форматирования, bidi/format-коды, некорректные surrogate. Пустые строки и начальный `/` отклоняются. Обычная кириллица и простые emoji допустимы.

## Только текст, не исполнение

JSON не десериализуется в Minecraft Components, скрипты или команды. Объекты с text/clickEvent/hoverEvent не принимаются вместо строки. В отправке отсутствуют вызовы command dispatcher и signed-chat API; строка и ник создаются через Component.literal. Поэтому даже фрагмент команды внутри допустимой фразы остаётся печатным текстом, а не действием.

## Включение и повторная загрузка

В серверном TOML: systems.enableDelirium=true и deliriumChat.enabled=true. По умолчанию отдельный enabled=false; обновление само не включает чат.

OP level 2:

```mcfunction
/vitalstages reloadphrases
/vitalstages debug phrase @s
```

Для preview нужен survival, сознание выше 0 и личное разрешение. В отличие от обычной отправки preview не ждёт таймера и не требует низкого сознания. Он действительно публикует текст в настроенном радиусе — это не приватный предпросмотр.

Перезагрузка атомарная: новый список заменяет прежний только целиком после валидации. При ошибке сохраняется последний исправный набор. На первом запуске с невалидным файлом работает пустой набор. Пользовательский файл никогда не перезаписывается автоматически.

Игрок без OP может выполнить `/vitalstages deliriumchat off` или `on`, только для себя. Личный выбор сохраняется после смерти/перезапуска. Обычная помощь лекарствами этого выбора не меняет.

## Когда срабатывает

Живой survival/adventure игрок в сознании 0 < C ≤ maximumConsciousness (default 35), не в обмороке. Между сообщениями учитывается сохранённый остаток online-тиков, default 45–120 с. Есть общий предел одной автоматической реплики в секунду на сервер. Сразу одинаковая строка не повторяется, если в файле хотя бы две уникальные строки; одна строка может повторяться после cooldown. Последняя строка сравнивается по содержимому, так что перестановка файла не ломает anti-repeat.

Слушатели: то же измерение и radiusBlocks (default 32). Радиус 0 — всё измерение. Личный opt-out запрещает говорить от своего персонажа; это не фильтр чужих реплик. Никаких фоновых задач или сетевых запросов для фраз нет.
