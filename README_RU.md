# Vital Stages 0.2.0 — MVP-2

Minecraft Java 1.21.1 / NeoForge 21.1.233 / JDK 21 / Gradle 9.2.1.

## Добавлено

- Рабочие переломы рук/ног: штрафы движения, скорости атаки и добычи через стабильные transient AttributeModifier. Чужие модификаторы и base value не затрагиваются.
- Шина для себя и напарника. Один предмет фиксирует один перелом и сразу снимает его штраф; сращивание требует времени.
- Сохранение прогресса заживления ран и сращивания. Восстановившиеся раны удаляются; HP/кровь не создаются и окно спасения не сбрасывается.
- Анатомический HUD с шестью частями тела, полосами крови/сознания, HP и сохранённой температурой.
- Клавиша H для показа/скрытия HUD, клиентский конфиг позиции/масштаба, собственные иконки бинта и шины.
- Отладочные OP-команды для воспроизводимого тестирования.
- Исправление Gradle 9 failOnNoDiscoveredTests=false уже включено. Проверки моделей НЕ отключены.
- Новый пункт плана: автоматические реплики бреда из пользовательского JSON. В 0.2.0 авточат ещё НЕ реализован.

## Обновление

1. Сделайте backup мира, включая playerdata и serverconfig.
2. Замените содержимое корня проекта содержимым папки vitalstages из ZIP. Сохраните свои сторонние изменения отдельно.
3. Соберите новую версию. Удалите старый JAR Vital Stages из mods; установите только одну новую версию на сервер и все клиенты.
4. Конфиг мира удалять не надо: новые значения добавляются с defaults.

NBT версии 1 читается с сохранением крови, ран и уже потраченного окна обморока. Новое healingTicks получает 0. При сохранении пишется версия 2; старый мод не должен открывать обновлённое сохранение. Откат — через backup. Сетевой протокол изменён на 2: обновляются обе стороны.

## Сборка

Нужны JDK 21, Gradle 9.2.1 и интернет к зависимостям Minecraft/NeoForge.

```sh
gradle --no-daemon build
gradle runClient
gradle runServer
```

Результат: build/libs/vitalstages-0.2.0.jar, не -sources.jar. GitHub Actions workflow сохранён; после успешной сборки скачайте artifact vitalstages-jars.

build запускает physiologyTest, mvp2Test и mvp2NbtTest. Стандартная test не падает из-за отсутствия JUnit, поскольку проверки реализованы JavaExec-задачами. Готовый непроверенный JAR и фиктивный Gradle Wrapper в архив не добавлены.

Офлайн-проверки без Minecraft:

```sh
sh scripts/test-core.sh
```

## Штрафы по умолчанию

Одна нефиксированная нога оставляет 55% движения, две — 30.25%. Одна рука оставляет 65% скорости атаки и 60% добычи; две — 42.25% и 36%. Фиксация снимает штраф только соответствующей конечности.

При creative/spectator или enableFractures=false штрафы снимаются, но раны сохраняются. Стабильные ID и transient исключают накопление при тиках/login/Clone/dimension. Модификаторы обновляются только при изменении значения.

Падение поражает ноги. Сильное ранение руки/ноги может дополнительно вызвать перелом: default-порог 6 HP фактически прошедшего урона, вероятность 35%. Дополнительная запись не удваивает боль/шок того же удара.

Клинические переломы головы/торса, точность снарядов и ограничение высоты прыжка этим этапом не добавлены.

## Предметы

- Бинт: любая шерсть + нить → 4 бинта.
- Шина: 2 палки + нить + бинт → 1 шина, бесформенный крафт.
- ПКМ в воздух — себе; ПКМ по игроку — напарнику.
- Сервер проверяет живое состояние, сознание лечащего, предмет, видимость, расстояние до 3 блоков и cooldown.
- Шина выбирает наиболее тяжёлый нефиксированный перелом конечности, с повышенным весом ног. Одна шина — одна цель.
- При отсутствии цели предмет не тратится. Cooldown шины 40 тиков, бинта 30.
- Ни бинт, ни шина напрямую не восстанавливают кровь, HP или сознание.

```mcfunction
/give @s vitalstages:bandage 16
/give @s vitalstages:splint 8
```

## Восстановление тканей

Defaults: ушиб 120 игровых секунд; перевязанный CUT 180; ожог 300; зафиксированный перелом 600. Открытый CUT сам не закрывается, руки/ноги без шины не срастаются.

Нужен стабильный организм: нет criticalTrauma и кровь выше порога кровяной комы, либо система крови выключена. При ухудшении и офлайн прогресс приостанавливается. Новый удар в тот же агрегат сбрасывает его healingTicks и перевязку/фиксацию, но НЕ таймер обморока.

## HUD и конфиги

Символы: x — перелом, + — шина, ! — рана, B — открытый CUT. Анатомические стороны именуются относительно игрока. H переназначается в Controls. H/F1 не меняют серверную физиологию и не отменяют blackout.

Клиент: config/vitalstages-client.toml — showAnatomyHud, hudScale, hudX, hudY. Панель уменьшается на маленьком экране и оставляет место vanilla HUD снизу.

Сервер: world/serverconfig/vitalstages-server.toml. Раздел fractures: movementPerLeg, attackSpeedPerArm, miningSpeedPerArm, heavyHitThreshold, heavyHitFractureChance, splintCooldownTicks. Раздел recovery: bruiseSeconds, bandagedCutSeconds, burnSeconds, splintedFractureSeconds. Старые настройки сохранены.

Температура пока только хранится/отображается; климатический расчёт не добавлен. Инфекция пока ограничена таймером/риском, без заболевания.

## Быстрый игровой QA (OP level 2)

```mcfunction
/vitalstages debug fracture @s left_leg
/vitalstages debug fracture @s right_arm
/give @s vitalstages:splint 8
```

Для проверки штрафов нужен survival. После шины один x должен стать +. Для быстрого сращивания временно задайте splintedFractureSeconds=5. Отладочный сброс организма и HP:

```mcfunction
/vitalstages debug reset @s
```
