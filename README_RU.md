# Vital Stages 0.3.0 — MVP-3

Minecraft Java 1.21.1 • NeoForge 21.1.233 • JDK 21 • Gradle 9.2.1 • ModDevGradle 2.0.143.

## Этот этап

Антисептик, обезболивающее, адреналин, добровольное донорство и переливание крови. JSON-реплики перенесены из будущего визуального этапа в MVP-3 и реализованы в коде: обычный вид `<Ник> текст`, без `[Бред]`.

Всё из MVP-2 сохранено: раны, кровопотеря без пассивной регенерации, обморок/окно спасения, бинт, переломы/шины, сращивание, анатомический HUD, клиентские эффекты, server-side ограничения действий.

Это исходники, не заранее собранный игровой JAR. Реально исполненные проверки и непроверенные участки перечислены в VALIDATION_RU.md.

## Сборка и установка

1. Сделайте backup мира, включая playerdata/serverconfig. Сохраните свои изменения исходников отдельно.
2. Замените исходники содержимым папки vitalstages из архива. Повторно добавлять вчерашние Gradle-патчи не нужно: оба уже включены.
3. С JDK 21 и Gradle 9.2.1 выполните:

```sh
gradle --no-daemon clean build
```

4. После зелёной сборки установите `build/libs/vitalstages-0.3.0.jar` на сервер и все клиенты. Удалите предыдущий JAR; не устанавливайте рядом две версии. `-sources.jar` не является игровым модом.

GitHub Actions: workflow в .github/workflows/build.yml собирает проект и прикладывает vitalstages-jars. В ZIP нет фиктивного wrapper JAR и нет непроверенного бинарного мода.

NBT версии 1/2 читается с прежними кровью, ранами, фиксацией, healingTicks и временем обморока. Новые лекарства получают безопасные defaults. Теперь записывается NBT 3; downgrade — через backup. Сетевой протокол 3 передаёт активные препараты: обе стороны должны обновиться.

## Новые предметы

| Предмет | Действие по умолчанию | Важное ограничение |
| --- | --- | --- |
| Антисептик | Сбрасывает риск/возраст загрязнения одной CUT/BURN; защищает 300 с | Не перевязывает и не останавливает кровь |
| Обезболивающее | 120 с маскирует 35 единиц боли | Не удаляет raw pain/раны; нельзя давать бессознательному; не складывается |
| Адреналин | Будит стабилизированного пациента; бонус сознания 30 на 20 с | Нет критической травмы/кровотечения, кровь ≥25; cooldown пациента 180 с |
| Пустой пакет | Добровольно забирает у себя 20 крови и создаёт полный пакет | Кровь ≥70, HP ≥75%, сознание ≥80, нет кровотечения; cooldown 300 с |
| Пакет крови | Добавляет до 20 крови, максимум 100 | HP и раны не лечатся; остаток дозы теряется; одноразовый |

Все продолжительности — online game seconds (20 ticks), не wall-clock. При низком TPS реальные секунды длиннее. Сила/длительность лекарств и cooldown настраиваются в серверном конфиге; размер пакета фиксирован 20 для сохранения баланса уже созданных предметов.

ПКМ в воздух — себе; ПКМ по игроку — помочь ему. Пустой пакет всегда берёт кровь только у самого использующего: принудительного забора у цели нет. Нужны расстояние до 3 блоков и видимость. При отсутствии подходящей цели лекарство не тратится. Creative имеет обычное административное исключение расхода; survival не создаёт кровь из пустоты.

После приёма HUD показывает `P` (обезболивание) и `A` (адреналин). Отображаемый визуальный штраф боли учитывает обезболивание, но attachment/capability продолжает хранить настоящую боль.

Антисептик работает с модельным риском. Для роста риска включите systems.enableInfection; по умолчанию он выключен ради совместимости. Полноценное инфекционное заболевание ещё не добавлено.

## Крафты

Все новые крафты бесформенные; это игровые рецепты, а не реальные способы изготовления медикаментов.

- Антисептик: стеклянная бутылочка + сахар + пчелиные соты → 1.
- Обезболивающее: бумага + сахар + сушёная ламинария → 2.
- Адреналин: стеклянная бутылочка + кусочек золота + сахар → 1.
- Пустой пакет: стеклянная бутылочка + бумага + нить → 1.
- Полный пакет НЕ имеет survival-крафта: его наполняет донор.
- Бинт: любая шерсть + нить → 4. Шина: 2 палки + нить + бинт → 1.

```mcfunction
/give @s vitalstages:antiseptic 8
/give @s vitalstages:painkiller 8
/give @s vitalstages:adrenaline 4
/give @s vitalstages:empty_blood_bag 8
/give @s vitalstages:blood_bag 4
```

## Помощь при обмороке

1. Бинтом остановить открытый CUT.
2. Если мало крови — перелить пакет.
3. При criticalTrauma сначала восстановить vanilla HP (например, существующим в игре лечением). Порог reviveHealth по умолчанию 4 HP. Адреналин сам HP не создаёт.
4. После стабилизации дать адреналин. Он не применяется к уже умершему игроку.
5. Очнувшемуся можно дать обезболивающее и продолжить лечение. Стимулятор временный: после истечения симптомы могут вернуться.

Пациентский cooldown сохраняется в NBT, так что несколько помощников/стаков и перезаход не обходят ограничение. Реальное пробуждение сбрасывает окно обморока; неудачная инъекция, перевязка и повторный урон его не продлевают.

## Реплики бреда

Подробная инструкция: JSON_CHAT_RU.md. При первом запуске создаётся пустой серверный файл:

`config/vitalstages/delirium_phrases.json`

Добавьте свои строки в phrases. В серверном `world/serverconfig/vitalstages-server.toml` задайте:

```toml
[deliriumChat]
    enabled = true
    minIntervalSeconds = 45
    maxIntervalSeconds = 120
    radiusBlocks = 32.0
    maximumConsciousness = 35.0
```

Это пример значений существующего раздела, не добавляйте второй `[deliriumChat]`. Общий systems.enableDelirium также должен быть true. После изменения TOML перезапустите сервер; JSON можно перечитать без перезапуска:

```mcfunction
/vitalstages reloadphrases
```

Случайная фраза выводится от персонажа, пока он жив, в сознании выше 0 и не выше порога. Бессознательные, мёртвые, creative/spectator молчат. Начальный cooldown нового игрока 45 с; затем он тикает даже при хорошем самочувствии. Между отправками — 45–120 с по умолчанию; разные фразы не повторяются подряд. Область слышимости — текущее измерение в пределах радиуса. 0 означает всё измерение.

Личное отключение, доступное без OP:

```mcfunction
/vitalstages deliriumchat off
/vitalstages deliriumchat on
```

Opt-out, последний текст и остаток cooldown переживают смерть/перезаход/измерение. Обычная смерть очищает активные препараты, но сохраняет cooldown донорства/адреналина. Это предотвращает сброс ограничений через respawn.

## Конфиги и HUD

Сервер: world/serverconfig/vitalstages-server.toml. В singleplayer: saves/<мир>/serverconfig/vitalstages-server.toml. Установленный level-name может отличаться от world.

Новые ключи раздела medicines: painkillerSeconds, painRelief, antisepticSeconds, adrenalineSeconds, adrenalineCooldownSeconds, adrenalineConsciousnessBonus, adrenalineMinimumBlood, donationMinimumBlood, donationCooldownSeconds, medicineCooldownTicks. Cooldown использования предмета по умолчанию 40 ticks, отдельно от длительных cooldown пациента/донора.

Клиент: config/vitalstages-client.toml, showAnatomyHud/hudScale/hudX/hudY. H переключает анатомию и переназначается в Controls. H/F1 не отменяют бессознательность и server-side ограничения.

Из MVP-2: одна нефиксированная нога даёт ×0.55 движения, рука ×0.65 attack speed/×0.60 mining speed. Множители разных конечностей перемножаются. Шина снимает свой штраф сразу, а перелом срастается по таймеру. Defaults: ушиб 120 с, перевязанный CUT 180 с, ожог 300 с, зафиксированный перелом 600 с. Прогресс требует стабильности и не восполняет кровь/HP.

## Быстрый QA (копия мира, OP level 2)

- `/vitalstages debug cut <player>` — порез для проверки бинта/антисептика.
- `/vitalstages debug fracture <player> left_leg` — перелом (также right_leg/left_arm/right_arm).
- `/vitalstages debug syncope <player>` — заменяет организм тестовым: кровь 25, боль 80, обморок, полный vanilla HP, нет ран/критической травмы. Нужен живой напарник с адреналином, окно по умолчанию 60 с. Не используйте в ценном сохранении.
- `/vitalstages debug phrase <player>` — немедленная проверка текста у сознательного survival-игрока. Игнорирует порог/таймер, но уважает включение, opt-out и доступность фраз.
- `/vitalstages debug reset <player>` — административно сбрасывает организм, HP и cooldown, но сохраняет личный opt-out. Это исключение для QA, не обычное возрождение.
