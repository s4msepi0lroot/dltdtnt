# Проверки MVP-2 (0.2.0)

## Реально выполнено

- Production-классы Physiology, BodyPart, FractureProfile, RecoveryClock и Wound скомпилированы с --release 21 и исполнены на доступной JVM 25.
- PhysiologyTest: PASS 41700 checks.
- Mvp2CoreTest: PASS 32509 checks. Все комбинации масок, штрафы, фиксация, ровно 12000 тиков сращивания, пауза, повторная травма, неизменяемость, числовые границы.
- Java 21 parse-only для 35 файлов в src: синтаксис, НЕ типизация Minecraft API.
- JSON/TOML, пути моделей/текстур/рецептов и отсутствие клиентских импортов в общем коде проверены.
- Обе иконки просмотрены отдельно. HUD внутри игры не был визуально проверен.

## Подготовлено для CI, но локально НЕ выполнено

mvp2NbtTest содержит 18 assertions с настоящими CompoundTag/ListTag, без NBT-заглушек: миграция формата 1, UUID/кровь/окно, формат 2, round-trip, независимая копия, фиксация/healingTicks, удаление сросшегося перелома, лимит 24 агрегатов, отказ от будущей версии.

Эта задача включена в gradle build. Локально Minecraft/NeoForge dependencies не загрузились (Maven DNS недоступен). Полный build и запуск 0.2.0 не объявляются проверенными. Старый пользовательский лог относился к 0.1.0.

## Игровой чек-лист перед релизом

1. Gradle build проходит physiologyTest/mvp2Test/mvp2NbtTest, test не падает из-за отсутствия JUnit.
2. OP-команда создаёт left_leg, survival замедляется; второй перелом даёт произведение множителей.
3. Одна шина снимает только один штраф; x меняется на +. Без цели предмет не расходуется.
4. Перелом руки меняет attack cooldown и добычу; шина восстанавливает множитель.
5. При splintedFractureSeconds=5 рана удаляется после времени, чужие атрибуты не затронуты.
6. Без шины/бинта соответствующий прогресс не идёт. При критической травме/кровяной коме он приостановлен.
7. Новый удар сбрасывает fixation/healingTicks, НЕ unconsciousTicks.
8. Копия мира MVP-1 открывается с прежними кровью, ранами и окном. Reconnect, restart, Nether/End clone не дублируют штрафы/раны.
9. Настоящий respawn очищает организм; creative/spectator/enableFractures=false снимают только наши штрафы.
10. Лечение через обе руки, расстояние, стену, пустой стек, обморок и повтор пакета проверяется сервером.
11. H/F1/GUI scale/размер окна: нет обрезания/пересечения с vanilla HUD, blackout не отключается.
12. Обе локализации и комбинация fracture+splint+open CUT читаются на одной части тела.
13. Клиент и сервер 0.2 совпадают по протоколу; смена сервера очищает визуальный кэш.
14. Регрессия MVP-1: обычный смертельный удар, кровь=0, тотем, /kill, пустота, чужая отмена death event.
15. Шаблон JSON реплик НЕ вызывает автоматического чата.
