# Проверки и ограничения

## Реально выполнено

- Чистый production-класс `Physiology.java` скомпилирован для Java 21 и выполнен вместе с `PhysiologyTest` на доступной JVM 25.
- Результат: **PASS: 41700 checks; deterministic scenarios + 10,000 randomized steps**.
- Сценарии: единицы кровопотери/секунду, отсутствие регенерации крови, обнуление крови, ровно 1200 тиков окна, отсутствие reset при повторном knockout, гистерезис, самовосстановление, ранняя/поздняя перевязка, критическая травма, отключение кровяной механики, NaN/Infinity и границы случайных состояний.
- Java compiler parser: **23 Java-файла** в `src`, синтаксис Java 21 без ошибок. Это parse-only, НЕ type-check Minecraft API.
- **14 JSON-ресурсов** (включая pack.mcmeta) и `neoforge.mods.toml` разобраны стандартными парсерами.
- Проверено отсутствие импортов `net.minecraft.client.*` в общем/серверном исходном коде.

## НЕ выполнено — обязательный gate перед релизом

- `gradle build` с реальным Minecraft/NeoForge classpath.
- Запуск клиента, dedicated server, shader/HUD screenshot QA, применение mixin-injectors.
- Реальный NBT round-trip через сохранение мира, persistence при reconnect и Clone в работающем сервере.
- Полноценный packet codec round-trip через RegistryFriendlyByteBuf.
- Проверка другого death/health/gravestone/anti-cheat мода.

Причина: из среды сборки не удалось загрузить внешние зависимости (DNS/сеть), установленного Gradle/кэшированного NeoForge нет. Готовый модовый JAR не предоставляется; в ZIP — реальные исходники и воспроизводимые команды, не фиктивный бинарник.

## Ручной интеграционный чек-лист

1. Собрать `gradle build`; запустить `runClient`, затем dedicated server и два клиента. Отсутствие classloading ошибок клиента на сервере.
2. Нелетальный урон: рана создаётся один раз. Щит и полное absorption: CUT не появляется. Проверить броню, зачарования, сопротивление.
3. Обычный смертельный удар: игрок жив, не открывается death-screen, C=0, виден blackout, напарник может нажать ПКМ бинтом.
4. Повторять смертельные удары: remaining window не возвращается к 60 секундам.
5. Довести кровь до нуля: настоящий death-screen и стандартные дропы/respawn. Повторить с тотемом/бронёй/resistance.
6. Ранний бинт: скорость уменьшается только за выбранный CUT, HP/кровь не прибавляются; при жизнеспособном остатке крови возможно пробуждение. При кровяной коме ниже порога бинта недостаточно.
7. Critical trauma: бинт + vanilla splash healing; критический флаг снимается после реального достижения reviveHealth.
8. Две открытые раны: первый бинт закрывает только одну, второй доступен после cooldown. Пустая перевязка не расходует предмет.
9. Другой игрок на дистанции >3 блока/за стеной/в другом мире: сервер отвергает лечение.
10. Выйти в середине обморока, перезапустить сервер, войти: раны, кровь и таймер прежние. Время офлайн не вычитается.
11. Nether-портал и End-exit clone: нет сброса/дублирования ран. Настоящая смерть/respawn: свежий организм.
12. Проверить F1, размер GUI, Esc, чат, смену сервера/мира, смерть и spectator: нет зависшего blackout и сохранённого клиентского кэша.
13. Попытки ударить, использовать предмет, переложить/выбросить стек, управлять лодкой в обмороке: сервер не выполняет действие.
14. Падение в обмороке, вода, knockback, транспорт, серверный teleport: отдельно оценить ограниченную физику MVP и конфликты движения.
15. Перезагрузка SERVER-конфига и переключение систем: скорость пересчитывается, раны не стираются, отключённая кровяная механика не держит в коме.
16. Другой мод отменяет LivingDeathEvent: нет HP=0 softlock и рекурсивной бесконечной смерти за один тик; повтор не чаще секунды.

41 700 проверок модели — не 41 700 игровых интеграционных тестов. Публично называть сборку production-ready до этих проверок нельзя.
