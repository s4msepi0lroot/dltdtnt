# Проверки 0.3.0

## Реально выполнено в этой среде

- Java-компиляция чистых production-классов с --release 21; выполнение на доступной Corretto JVM 25.
- PhysiologyTest: PASS 41700 checks.
- Mvp2CoreTest: PASS 32509 checks.
- Mvp3CoreTest: PASS 45824 checks.
- Всего 120033 реально исполненных assertions/checks, включая детерминированные сценарии и псевдослучайные регрессии. Это не утверждение о 120033 независимых end-to-end сценариях.
- Java 21 parse-only для 48 файлов src: 43 main, 5 tests. Это синтаксис, не типизация новых Minecraft API.
- JSON/TOML, 7 пар model/texture, 16×16 PNG, отсутствие рецепта полного пакета, разделение common/client imports.
- Проверен исходный маршрут чата: literal ник/текст, нет command dispatcher/player-chat signing, ограниченное чтение, default off.
- Пять новых иконок просмотрены отдельно на увеличенных previews. Игровой HUD и сообщение внутри Minecraft не рендерились здесь.

## Подготовлено для CI, не исполнено здесь

- mvp2NbtTest: настоящие CompoundTag/ListTag, миграция старого формата, round-trip, copy, восстановление ран; ожидание версии обновлено на текущую/следующую.
- mvp3IntegrationTest: реальный Gson strict parser, невалидный JSON/UTF-8/лимиты, NBT 1/2→3, лекарства/opt-out/cooldown, донорство, адреналин и переливание.
- Full NeoForge compile/build, старт клиента/сервера и сетевой round-trip.

Причина: локально нет Gradle/Minecraft classpath, DNS Maven недоступен. Не используются фальшивые Minecraft/NBT заглушки. Предыдущий пользовательский лог подтверждал компиляцию основной версии 0.2.0; он не доказывает компиляцию 0.3.0.

## Команды

```sh
sh scripts/test-core.sh
java --source 21 scripts/JavaSyntaxCheck.java src
gradle --no-daemon clean build
gradle --no-daemon mvp2NbtTest mvp3IntegrationTest
```

Все пять JavaExec-задач обязательны для check. Стандартная test не падает из-за отсутствия JUnit, но явные main()-проверки не отключены. Minecraft/NeoForge добавлены к compile/runtime classpath тестов; это второй патч из пользовательского CI-лога.

## Игровой чек-лист

1. Backup мира, зелёный Gradle build, один JAR версии 0.3.0 на обеих сторонах.
2. Порез → антисептик сохраняет рану/кровотечение, затем бинт останавливает кровь. Защита истекает; новая травма сбрасывает её.
3. Обезболивающее при боли → P, меньший визуальный/физиологический штраф, сырая боль не обнуляется. Повтор не тратит предмет.
4. Полный здоровый игрок использует один пустой пакет: кровь 100→80 и ровно один полный пакет. Проверить обе руки, стек из одного/нескольких, полный инвентарь и выпадение результата.
5. Повторная сдача запрещена при cooldown; смерть/reconnect/End не обходят ограничение. Полный пакет не имеет survival-рецепта.
6. Переливание при 95 добавляет только 5 и тратит одну дозу, при 100 предмет не тратится; HP не меняется.
7. Два survival-игрока: debug syncope на пациенте, напарник даёт адреналин, тот просыпается. Нельзя дать таблетку бессознательному, лечить через стену/дистанцию/мёртвую цель.
8. После адреналина повторная травма/другой помощник не обходят cooldown. При criticalTrauma нужен vanilla HP heal; инъекция не отменяет окно автоматически.
9. В копии старого мира не меняются кровь/таймер/раны/шины; лекарства и opt-out сохраняются после restart/dimension/non-death Clone. Реальная смерть очищает организм и активные лекарства, не preference/cooldown.
10. JSON пуст → тишина. Заполнить две строки, включить конфиг, reload, debug phrase → `<Ник> текст`, без `[Бред]`. Это реальная публикация в радиусе, не приватный preview.
11. Отправка только при C≤порога, C>0, нет unconscious, survival/adventure. Учитываются интервалы и общий rate limit. Смена измерения/reconnect не обнуляют ожидание.
12. Личный off/on без OP работает только для себя; debug/reload недоступны без OP 2. Opt-out переживает смерть и debug reset.
13. Ломаный JSON, объекты clickEvent, повтор ключа, `/op`, перенос строки, bidi, размер >64 KiB → reload отклонён, последний рабочий набор остаётся.
14. Радиус и разные измерения; сообщения не имитируют подписанный ввод, проверить совместимость с chat-плагинами/фильтрами.
15. H/F1/GUI scale/resize/RU/EN: новый P/A-индикатор не пересекает заголовок, blackout не отключается.
16. Регрессия прежних переломов/сращивания, финальной смерти, /kill/void/totem и сторонней отмены смерти.
