# 0.3.0 — MVP-3

- Новые MedicalRules/TreatmentState/TreatmentNbtCodec; антистек лекарств и сохранённые cooldown.
- Антисептик, обезболивающее, адреналин, пустой/полный пакет крови. Переливание не создаёт HP, survival-донорство переносит 20 крови.
- Обезболивание сохраняет raw pain; критическая травма и кровяная кома остаются сильнее стимуляторов.
- Реализованы JSON-реплики: `<Ник> текст` без `[Бред]`, только серверный literal text. По запросу перенесены из более позднего этапа.
- Строгий ограниченный JSON, атомарный reload, локальная слышимость, anti-repeat, cooldown, личное отключение.
- HUD P/A, 5 новых оригинальных иконок, RU/EN, 4 рецепта. Полный пакет не крафтится.
- Добавлены OP-команды cut/syncope/phrase; debug/reload защищены level 2, личный opt-out не требует OP.
- NBT 3 мигрирует 1/2; сеть 3. Смерть не сбрасывает opt-out и антиспам/пациентские cooldown.
- Включены оба Gradle-исправления: failOnNoDiscoveredTests=false и compile/runtime classpath Minecraft/NeoForge для тестов. Все пять JavaExec suites подключены к check, запуск закреплён на Java 21.

## История

0.2.0: переломы/шины/заживление/HUD, NBT 2, протокол 2. Тогда JSON-реплики были только планом; теперь они реализованы в исходниках.
0.1.0: базовая многоступенчатая физиология, сеть, сохранения, бинт и эффекты.
