# DeltaDotNet

Кооператив по сети для игр с локальным мультиплеером на одной клавиатуре
(создавалось под моды к Deltarune). Хост запускает игру у себя, остальные
видят картинку и жмут свои кнопки на своих клавиатурах.

```
Игрок 1 (хост)            релей-сервер            Игроки 2-4
────────────────            ────────────            ──────────
скрин → JPEG ──────────→  Node.js  ──────────→ окно трансляции
нажатия в игру ←────────  WebSocket ←──────── нажатия клавиш
```

Связь не p2p: всё идёт через лёгкий релей-сервер без внешних зависимостей
(чистый Node.js, собственная реализация WebSocket).

## Что умеет

- Лобби на 2-4 игроков, вход по короткому коду.
- Трансляция окна игры или всего экрана всем участникам.
- Настройки качества: FPS, сжатие JPEG, ширина картинки + три пресета.
- Своё управление у каждого игрока + настройка клавиш, которые хост шлёт в игру.
- Открытые и закрытые лобби: вход свободный, по паролю или по списку логинов.
- Хост может кикать, банить, снимать бан и закрывать лобби одной кнопкой.
- Админ-панель для владельца сервера: переливающиеся ники, теги, баны,
  роли, сброс пароля, закрытие чужих лобби, рассылка объявлений, статистика.
- Оформление в стиле Deltarune и свои картинки для логотипа и иконок.

## Быстрый старт

```bash
# сервер
cd server
cp .env.example .env      # обязательно поменяйте AUTH_SECRET и ADMIN_LOGIN
node src/index.js

# проверка
curl http://127.0.0.1:8080/health
node e2e-test.js
```

Клиент собирается в один exe без установленного .NET:

```bash
dotnet publish client/DeltaDotNet.Client/DeltaDotNet.Client.csproj \
  -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -o out
```

Или просто залейте репозиторий на GitHub — воркфлоу `.github/workflows/build.yml`
соберёт `DeltaDotNet.exe` и положит его в артефакты сборки.

## Картинки

Свой логотип и иконки кладутся в `client/DeltaDotNet.Client/assets/`
(или рядом с готовым exe в папку `assets`). Подробности — в `assets/README.md`
и в `docs/USAGE.md`.
