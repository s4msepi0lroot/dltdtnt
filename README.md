# DeltaDotNet

Онлайн-надстройка над **локальным** мультиплеер-модом (сделано под Deltarune).

Мод умеет играть только вдвоём за одной клавиатурой. DeltaDotNet делает так, что
второй (третий, четвёртый...) игрок сидит у себя дома: **хост** транслирует
картинку игры, **гости** нажимают клавиши у себя, а хост подставляет эти нажатия
в игру так, будто они пришли со второй половины его клавиатуры.

```
  гость (клавиши)  ──WS──►  сервер Node.js  ──WS──►  хост  ──SendInput──►  игра
  гость (картинка) ◄─WS──   сервер Node.js  ◄─WS──   хост  ◄──BitBlt────   игра
```

P2P нет: весь трафик идёт через ваш сервер.

## Что внутри

| Папка | Что это |
|---|---|
| `server/` | Node.js: аккаунты, токены, лобби, ретрансляция видео и ввода, админ-команды |
| `client/DeltaDotNet.Client/` | C# WPF клиент в стилистике Deltarune (хост и гость — одно приложение) |
| `client/DeltaDotNet.ThemeStudio/` | C# WPF редактор тем, собирает файлы `.ddntheme` |
| `.github/workflows/build.yml` | Сборка на GitHub Actions: два `.exe` + архив сервера |
| `docs/` | Полная документация |

## Быстрый старт

1. Залейте репозиторий на GitHub → вкладка **Actions** → workflow «build DeltaDotNet»
   соберёт `DeltaDotNet-client-win-x64` и `DeltaDotNet-themestudio-win-x64`.
2. Поднимите сервер (`docs/02-server.md`), например на VPS:
   ```bash
   cd server && npm install
   DDN_SECRET=любая_длинная_строка DDN_ADMIN_USERNAME=s4msepi0l npm start
   ```
3. Запустите клиент, впишите адрес сервера `http://ваш_адрес:8080`,
   зарегистрируйтесь. Аккаунт **s4msepi0l** автоматически получает админку.
4. Хост запускает игру и мод, создаёт лобби, остальные заходят по ID.
5. Хост жмёт **START THE GAME**.

## Куда класть свои картинки

Все картинки не вшиты в код — просто положите файлы в `Assets/` рядом с проектом,
они копируются в сборку автоматически. Ничего не положили — будет текстовый
фолбэк, сборка не сломается.

**`client/DeltaDotNet.Client/Assets/`**

| Файл | Что это |
|---|---|
| `app.ico` | иконка `DeltaDotNet.exe` (настоящий `.ico`, внутри 16/32/48/256) |
| `logo.png` | логотип в шапке клиента вместо надписи `DELTA.DOTNET` (высота ~48 px) |
| `icon.png` | иконка окна |
| `heart.png` | сердечко-курсор в списках (необязательно) |
| `bg.png` | фоновая картинка по умолчанию |
| `banner.png` | картинка на экране входа |

**`client/DeltaDotNet.ThemeStudio/Assets/`**

| Файл | Что это |
|---|---|
| `app.ico` | иконка `DeltaDotNet.ThemeStudio.exe` |
| `logo.png` | логотип в шапке редактора тем |

После добавления `app.ico` строчка `<ApplicationIcon>` в `.csproj` подхватит его
сама (там стоит `Condition="Exists(...)"`).

## Важное предупреждение

Хост отдаёт своему компьютеру нажатия чужих клавиш через `SendInput` — они
уходят в активное окно. Пускайте в лобби только тех, кому доверяете, и держите
игру в фокусе. Закрытые лобби с паролем/списком гостей для этого и сделаны.
