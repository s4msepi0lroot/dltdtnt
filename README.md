# CoopStream

Онлайн-кооп для игр с локальным мультиплеером на одной клавиатуре.
Один игрок (хост) запускает игру у себя, второй видит трансляцию и играет со своей клавиатуры.
Всё идёт через ваш собственный релей-сервер — никакого P2P и проброса портов.

```
Игрок 2 (гость)          Релей-сервер           Игрок 1 (хост)
  ViewerForm    --input-->   Node.js WS   --input-->   SendInput --> ИГРА
  PictureBox    <--JPEG---    /ws         <--JPEG---   захват экрана
```

## Что внутри

| Компонент | Технологии | Назначение |
|---|---|---|
| `server/` | Node.js 18+, **ноль npm-зависимостей** (своя реализация WebSocket) | авторизация, лобби, ретрансляция кадров и клавиш |
| `client/` | C# .NET 8 WinForms (win-x64) | захват экрана, просмотр трансляции, инжекция клавиш |
| `.github/workflows/build.yml` | GitHub Actions | собирает `CoopStream.exe` и артефакт сервера |

## Раскладка клавиш

| Роль | Клавиши |
|---|---|
| **P1** | `W` `A` `S` `D`, `Z`, `X`, `P`, `C`, левый/правый `Ctrl`, левый/правый `Shift` |
| **P2** | `↑` `↓` `←` `→`, `Enter` (и `Enter` на нампаде), `C`, левый/правый `Ctrl`, левый/правый `Shift` |

Белый список проверяется **трижды**: в окне гостя, на сервере и перед инжекцией у хоста.
Хост своими клавишами играет напрямую — программа ему не мешает.

## Быстрый старт

1. **Сервер** (любая VPS / Railway / Fly.io / Docker):
   ```bash
   cd server
   AUTH_SECRET=$(node -e "console.log(require('crypto').randomBytes(32).toString('hex'))") node src/index.js
   ```
2. **Клиент**: скачайте `CoopStream.exe` из артефактов GitHub Actions — оба игрока.
3. Оба вводят адрес сервера (`ws://ваш-хост:8080/ws`), регистрируются, входят.
4. Хост создаёт лобби → получает код из 6 символов → гость вводит код → хост жмёт «Начать игру».

Подробнее — в [docs/USAGE.md](docs/USAGE.md).

## Ограничения

- Клиент только для Windows (использует GDI+ и `SendInput`).
- Клавиши гостя попадают в **активное** окно у хоста: игра должна быть в фокусе.
- Античиты и эксклюзивный полноэкранный режим могут блокировать захват и `SendInput`.
  Рекомендуется оконный (borderless) режим.
- Качество и задержка зависят от канала и расположения сервера.
