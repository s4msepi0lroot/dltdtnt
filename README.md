# SepiolSkins 0.1.0 — кирпич №2 sepiolSMP Season 2

Скины видны у **всех** игроков, с любого лаунчера, при `online-mode=false` и авторизации через AuthMe.

## Зачем это нужно

AuthMe требует `online-mode=false`. В оффлайн-режиме Mojang **не отдаёт** серверу текстуры игрока, поэтому все выглядят как Steve — и лицензионщики, и пираты. Решение: сервер сам находит скин и подставляет свойство `textures` в профиль игрока при входе. Клиенту при этом ничего не нужно: скин приходит с сервера, поэтому его видят все и на любой сборке.

## Как ищется скин

1. **Лицензия (Mojang)** — ник → uuid → подписанные текстуры. Работают у всех клиентов без исключений.
2. **Ely.by** — берём прямую ссылку на png и модель (classic/slim).
3. **MineSkin** — перезагружает png из Ely.by на `textures.minecraft.net` и отдаёт подписанные текстуры.

Шаг 3 обязателен: ванильный клиент принимает скины только с хостов Mojang, поэтому «сырую» ссылку Ely.by часть игроков просто не увидит. Если очень хочется без MineSkin — поставь `elyby.reupload-through-mineskin: false`, но тогда скины Ely.by гарантированно видны только тем, у кого в клиенте есть скин-лоадер.

Результат кешируется в `plugins/SepiolSkins/cache/<ник>.json` на `resolve.refresh-hours` часов. Ненайденные ники запоминаются на `negative-cache-minutes`, чтобы не долбить API.

## Логины никогда не висят

Поиск идёт в своём пуле потоков. У входа есть бюджет `resolve.login-timeout-seconds` (по умолчанию 4 сек): не успели — игрок заходит с тем, что было в кеше, а поиск догоняет в фоне и попадает в кеш к следующему входу.

## Локальные аватарки для веб-профиля

При `files.export-web-assets: true` плагин складывает:

```
plugins/SepiolSkins/web/skins/<ник>.png      # исходный скин
plugins/SepiolSkins/web/heads/<ник>.png      # голова 72x72 (со шляпой)
plugins/SepiolSkins/web/textures/<ник>.json  # источник, модель, ссылки, время
```

`SepiolCore` раздаёт их как `/avatar/<ник>` со своего порта — веб-профиль больше не зависит от minotar/crafatar.

## Команды

| Команда | Что делает | Право |
| --- | --- | --- |
| `/skin` | что сейчас стоит и откуда | `sepiolskins.use` |
| `/skin update [ник]` | принудительно пересканировать лицензию и Ely.by | `sepiolskins.use` / `.other` |
| `/skin from <ник>` | взять скин другого ника себе | `sepiolskins.use` |
| `/skin url <png> [slim]` | свой скин по ссылке (закрепляется) | `sepiolskins.use` |
| `/skin clear [ник]` | сбросить на стандартный | `sepiolskins.use` / `.other` |
| `/skin reload` | перечитать конфиг | `sepiolskins.admin` |
| `/skin purge` | очистить кеш скинов | `sepiolskins.admin` |

Если Paper на сборке умеет менять профиль на лету — скин применяется без перезахода, иначе плагин попросит перезайти.

## Сборка

```bash
cd sepiolskins
gradle wrapper --gradle-version 8.10   # один раз, если нет ./gradlew
./gradlew build
```

Jar: `build/libs/SepiolSkins-0.1.0.jar` → в `plugins/`. Нужен JDK 21. Внешних зависимостей нет: HTTP — из JDK, JSON — Gson из ядра сервера, рендер головы — ImageIO.

## Порядок с SkinsRestorer

Можно держать оба: SkinsRestorer оставляем для ручных команд и своих коллекций скинов, SepiolSkins закрывает автоматику и Ely.by. Если начнут конфликтовать (скин прыгает при входе) — выключи в SkinsRestorer автоприменение скинов при логине, приоритет отдай SepiolSkins.

## Проверка на сервере

1. `online-mode=false`, AuthMe включён.
2. Зайти лицензионным ником → скин с Mojang.
3. Зайти ником, у которого скин только на Ely.by → в логе `resolved from elyby+mineskin`.
4. `/skin info <ник>` → источник и время обновления.
5. Открыть `http://<домен>:8300/avatar/<ник>` → голова 72x72.
