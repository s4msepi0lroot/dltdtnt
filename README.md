# DeltaDotNet

Онлайн‑надстройка над локальным мультиплеер‑модом DELTARUNE: хост запускает игру у себя,
сервер раздаёт картинку остальным игрокам, а их клавиши прилетают обратно к хосту и
нажимаются в игре так, будто все сидят за одной клавиатурой.

```
  ┌──────────────┐   JPEG-кадры    ┌─────────────┐   JPEG-кадры    ┌──────────────┐
  │  ХОСТ (P1)   │ ───────────────▶│  DeltaDotNet│────────────────▶│ ГОСТЬ (P2..4)│
  │ игра + мод   │                 │   сервер    │                 │  только окно │
  │ SendInput    │◀─────────────── │  (Node.js)  │◀─────────────── │  клавиатура  │
  └──────────────┘   нажатия       └─────────────┘   нажатия       └──────────────┘
```

Ничего peer‑to‑peer: весь трафик идёт через ваш сервер, игрокам не нужно знать IP друг друга.

## Что внутри

| Папка | Что это |
|-------|---------|
| `server/` | Node.js сервер: аккаунты, лобби, ретрансляция видео и ввода, админ‑API |
| `src/DeltaDotNet.Core/` | Общая C#‑библиотека: протокол, настройки, биндинги, HTTP/WS клиенты, формат тем |
| `src/DeltaDotNet.Client/` | WPF‑клиент в стилистике DELTARUNE (лобби, игра, настройки, админка) |
| `src/DeltaDotNet.ThemeStudio/` | Отдельное приложение — конструктор тем `.ddntheme` |
| `.github/workflows/build.yml` | Сборка всего на GitHub Actions |
| `docs/` | Полная документация |

## Быстрый старт

1. Поднимите сервер: `cd server && npm install && node src/index.js`
   (или задеплойте на любой VPS / Railway / Render — см. `docs/server.md`).
2. Соберите клиент: залейте репозиторий на GitHub → вкладка **Actions** → workflow
   **Build DeltaDotNet** → артефакты `DeltaDotNet-Client-win-x64` и `DeltaDotNet-ThemeStudio-win-x64`.
3. Зарегистрируйте аккаунт `s4msepi0l` первым — он автоматически получает владельца и админку.
4. Хост создаёт лобби, гости заходят по коду, хост жмёт **START GAME**.

## Требования

- Клиент и Theme Studio: Windows 10/11 x64 (артефакты self‑contained, .NET ставить не нужно).
- Сервер: Node.js 18+ (тестируется на 20).
- У хоста должна быть запущена сама игра с локальным мультиплеер‑модом.
