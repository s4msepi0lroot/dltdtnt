# DeltaDotNet

Сетевая надстройка над локальным мультиплеерным модом для **Deltarune**: игра
запущена на одном компьютере (хост), но играют до четырёх человек с разных
машин, каждый со своей клавиатурой.

```
  P2 / P3 / P4                 relay-сервер                    P1 (хост)
  жмут свои клавиши  --действия-->  лобби  --действия-->  SendInput в игру
  видят картинку     <--кадры JPEG--         <--кадры--   захват экрана
```

Соединение **не P2P**: всё идёт через лёгкий relay-сервер на Node.js без
внешних зависимостей — его можно поставить на любой VPS или бесплатный хостинг.

## Что умеет

- Авторизация по логину и паролю (scrypt) и автовход по токену.
- Лобби с шестизначным кодом и **выбором количества игроков: 2, 3 или 4**.
- Трансляция экрана или отдельного окна игры всем участникам сразу.
- **Полностью переназначаемое управление** у каждого игрока, независимо от остальных.
- Интерфейс в стилистике Deltarune: чёрный фон, белые рамки, жёлтый выбор,
  красное сердечко-курсор.
- Сборка в GitHub Actions: один файл `DeltaDotNet.exe` без установки .NET.

## Главная идея управления

Сервер ничего не знает про клавиши. По сети ходят только **девять логических
действий**: `Up, Down, Left, Right, Confirm, Cancel, Menu, Extra1, Extra2`.

```
клавиша гостя  →  его личная привязка  →  действие  →  сервер  →
хост  →  клавиша, которую ждёт мод для этого игрока  →  SendInput
```

Благодаря этому игрок с ноутбука без цифрового блока и игрок с полноразмерной
клавиатуры могут играть совершенно разными кнопками, а в игре всё останется
так, как настроено в самом моде.

## Быстрый старт

```bash
# сервер (Node.js 18+)
cd server
AUTH_SECRET="длинная-случайная-строка" node src/index.js
# проверка: http://127.0.0.1:8080/health
```

Клиент скачивается из артефактов GitHub Actions (`DeltaDotNet-client-win-x64`) или
собирается локально:

```bash
dotnet publish client/DeltaDotNet.Client/DeltaDotNet.Client.csproj \
  -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -o out
```
