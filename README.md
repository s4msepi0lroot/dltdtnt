# SepiolFinale 0.1.0

Плагин управляемого конца сезона для **sepiolSMP** (Youer / Paper 1.21.1, Java 21).

Одна команда в день финала — и сервер сам разыгрывает конец мира: шторм → разлом →
сжимающаяся граница → все умирают → сервер выключается сам. До этой команды плагин
абсолютно пассивен и может весь сезон лежать в `plugins/`.

---

## Фазы

| # | Фаза | Ключ | Дефолт | Что происходит |
|---|------|------|--------|-----------------|
| 1 | Знамения | `omens` | 10 мин | Время замирает на закате, вечный шторм, редкие молнии, гул пещер. Ничего не ломается — время попрощаться и сбежаться на спавн |
| 2 | Разлом | `rift` | 10 мин | Граница ползёт к 2000, блоки вокруг игроков гниют (обсидиан/магма/паутина), PvP принудительно вкл, волны мобов каждую минуту, частые молнии |
| 3 | Схождение | `convergence` | 10 мин | Граница сжимается до 96 блоков, тех, кто снаружи, тянет к центру, верхние слои растворяются, с неба падает TNT, взрывы и пожары, регенерация отключена |
| 4 | Пепел | `ash` | 5 мин | Респавна больше нет: кто умер — стал зрителем навсегда. Урон каждую секунду, через 2 минуты оставшиеся добиваются гарантированно |
| 5 | Тишина | `silence` | 1 мин | Все зрители, мир заморожен, снимок итогов через SepiolCore, отсчёт, кик всех, метка `FINALE_DONE`, `Bukkit.shutdown()` |

Суммарно на дефолтах — **36 минут** шоу. Любая фаза настраивается по секундам в `config.yml`.

## Команды

Право: `sepiolfinale.admin` (по умолчанию — только op). Алиасы команды: `/sepiolfinale`, `/konec`.

| Команда | Что делает |
|---------|------------|
| `/finale status` | Фаза, таймер, живые/мёртвые, размер границы, режим |
| `/finale dry` | **Репетиция**: все 5 фаз в 10× быстрее, без разрушений, без смертей, без выключения |
| `/finale arm` | Выдаёт одноразовый 4-значный код (живёт 5 минут) |
| `/finale start <код>` | Запуск настоящего финала |
| `/finale skip` | Следующая фаза прямо сейчас |
| `/finale phase <имя>` | Вручную включить фазу: `omens`, `rift`, `convergence`, `ash`, `silence` |
| `/finale abort` | Отмена + откат настроек мира из снимка, зрителей вернёт в выживание |
| `/finale restore` | Только вернуть настройки мира из `state.yml` |
| `/finale reload` | Перечитать `config.yml` |

### Сценарий дня финала

```
/finale dry            # за неделю до: прогнать шоу целиком на тестовом сервере
/finale arm            # в день финала
/finale start 4821     # поехали
```

## Защита от случайного апокалипсиса

1. **Код подтверждения.** `/finale start` без свежего кода не работает (`safety.require-code`).
2. **Снимок мира.** Перед стартом в `state.yml` уезжают граница, время, погода, PvP,
   сложность и 11 геймрулов. `/finale abort` возвращает их обратно.
3. **Репетиция.** `dry-run.destroy/kill/shutdown = false` — видно всё шоу (титры, чат, звуки,
   граница), но ни один блок не умирает.
4. **Перезапуск посреди финала.** Плагин сам ничего не возобновляет — только пишет в консоль
   предупреждение. Автовозобновление включается флагом `safety.auto-resume-after-restart`.
5. **Нет побега.** В фазах Пепел/Тишина игрокам блокируются команды (кроме списка
   `safety.allowed-commands`), а новые зашедшие сразу становятся зрителями.

## Нагрузка и TPS

- Тикер работает **5 раз в секунду**, а не раз в секунду: бюджет в 400 блоков/сек — это 80
  блоков за порцию, а не одна заметная просадка.
- Блоки меняются **только в загруженных чанках вокруг живых игроков** — удалённые чанки
  не грузятся ради шоу, которое никто не видит.
- `setType(..., false)` — без physics-каскадов на полмира.
- Защитные блоки (бедрок, порталы, командные блоки, барьеры, жидкости) не трогаются.

## Связка с остальной сборкой

- **SepiolCore** — в фазе Тишины вызывается снимок итогов сезона (через reflection, а если
  метода нет — через консольную `/sepiol snapshot`). Веб-профили переживут смерть мира.
- **badhabits / boozecraft** — у каждой фазы есть список `commands:`, который выполняется от
  консоли на входе в фазу. Поддерживается `%player%` — команда повторится для каждого
  онлайн-игрока. Например:

```yaml
phases:
  rift:
    commands:
      - "/badhabits set %player% narcotic 80"   # мир рвётся — и голова тоже
  convergence:
    commands:
      - "/give %player% boozecraft:hangover_cure 1"  # последняя милость
```

## Уничтожение мира после выключения

Плагин сознательно **не удаляет папку мира сам** — удалять файлы из-под работающего
сервера — самый надёжный способ потерять всё неправильно. Вместо этого он пишет
метку-файл `FINALE_DONE` рядом с папками миров и выключается.

Дальше работает `scripts/after-finale.sh`:

```bash
./scripts/after-finale.sh /path/to/server
# systemd: ExecStopPost=/path/to/after-finale.sh /path/to/server
```

Он архивирует `world`, `world_nether`, `world_the_end` в `backups/` и удаляет их — но только
если метка на месте. Обычный стоп сервера мир не трогает.

## Ключи config.yml

| Ключ | Смысл |
|------|--------|
| `finale.world` | Мир финала, `auto` = первый мир |
| `finale.center` | `spawn` или `"x,z"` — точка схождения |
| `finale.season-name` | Имя сезона в сообщениях |
| `dry-run.time-scale` | Ускорение репетиции (0.1 = 10×) |
| `safety.*` | Код, TTL кода, автовозобновление, блокировки команд и входа |
| `phases.<фаза>.seconds` | Длительность фазы |
| `phases.rift.corrosion-per-second` | Сколько блоков/сек гниёт |
| `phases.convergence.dissolve-per-second` | Сколько блоков/сек исчезает |
| `phases.ash.kill-remaining-after` | Через сколько секунд добивать выживших |
| `phases.silence.shutdown` | Выключать ли сервер |
| `phases.silence.marker-file` | Имя метки для скрипта удаления мира |
| `messages.*` | Все титры и тексты (цвета через `&`) |

## Сборка

```bash
gradle wrapper --gradle-version 8.12.1   # один раз
./gradlew build
# build/libs/SepiolFinale-0.1.0.jar
```

Требуется JDK 21. Зависимостей, кроме `paper-api` (compileOnly), нет — jar чистый.

### GitHub Actions

`.github/workflows/build.yml` собирает jar на каждый push и PR (JDK 21 + Gradle 8.12.1),
кладёт его в artifacts как `SepiolFinale-jar`, а по тегу `v*` ещё и приклеивает jar к релизу:

```bash
git tag v0.1.0 && git push origin v0.1.0
```

- [ ] Сделан ручной бэкап мира и `plugins/` (кроме автоматического)
- [ ] В `phases.*.commands` проверены все команды модов
- [ ] Скрипт `after-finale.sh` привязан к systemd/врапперу и протестирован без метки
- [ ] Авторестарт сервера в хостинг-панели ОТКЛЮЧЁН — иначе мир воскреснет
- [ ] Запись шоу включена до `/finale start`
