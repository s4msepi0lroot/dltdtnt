# SepiolEconomy 0.1.1

> **0.1.1 — фикс сборки.** Компонент record `PayResult.wait` переименован в `waitSeconds`: имя `wait`
> запрещено для компонентов record, потому что конфликтует с финальным методом `Object.wait()`,
> из-за чего `result.wait()` компилятор считал вызовом `void`-метода. Логика не менялась.

Валюта сезона «sepiolSMP» — **сепиол**. Кирпич № 4 сборки Season II (Youer 1.21.1 = Paper + NeoForge).

## Главный принцип

Деньги в мир приходят **только** через банк сезона, который скупает ресурсы
по плавающему курсу. Банк **ничего не продаёт** — предметы только добываются
или покупаются у игроков. Поэтому экономика не умирает к второй неделе сезона:

1. **Плавающий курс.** Каждая сдача роняет цену именно этого ресурса.
   Квота (`quota`) — сколько штук надо сдать, чтобы цена упала вдвое.
2. **Самовосстановление.** Насыщение гаснет по полураспаду (по умолчанию вдвое за 24 ч).
3. **Суточный лимит эмиссии.** После 5000 сепиолов в сутки банк платит вдвое меньше.
4. **Комиссия за переводы.** 5 % с каждого `/pay` уходит в казну сезона (или сжигается).
5. **Контрабанда не принимается.** Сигареты, таблетки, сыворотки и прочая химия
   из `badhabits` легально не сдаётся — это товар для чёрного рынка (кирпич № 5).

## Что умеет

- Счета по UUID + кэш ников (корректно работает в offline-режиме с AuthMe).
- Стартовый капитал **20 сепиолов** при первом входе.
- `/balance [ник|top]`, `/pay <ник> <сумма>` (с комиссией), `/bank ...`, `/seco ...`.
- Витрина `/bank` — GUI с живыми ценами: ЛКМ сдать всё, Shift+ЛКМ — стак, ПКМ — цена.
- ~110 позиций курса, включая предметы твоих модов (`boozecraft:*`, `badhabits:*`).
- Защита от слива артефактов: предметы с именем, лором, чарами, PDC или поломкой банк не берёт
  (реликвии и именные вещи невозможно продать серверу).
- Мост в **Vault** без компиляционной зависимости (динамический прокси): любой плагин,
  умеющий работать с Vault, увидит наши сепиолы.
- Журнал всего (`ledger/<дата>.jsonl`) — для разборов скама и аудита инфляции.
- Выгрузка `web/economy.json` — топ богатеев и курс для веб-профиля (SepiolCore).
- API для следующих кирпичей: `Bukkit.getServicesManager().load(EconomyApi.class)`.

## Команды

| Команда | Что делает |
| --- | --- |
| `/balance` (`/bal`, `/money`) | свой счёт |
| `/balance <ник>` | счёт игрока (право `sepioleconomy.balance.other`) |
| `/balance top` | топ сезона |
| `/pay <ник> <сумма>` | перевод, комиссия 5 % сверху |
| `/bank` | витрина курса |
| `/bank quote [кол-во]` | сколько дадут за предмет в руке |
| `/bank sell [кол-во\|hand\|all]` | сдать предмет из руки |
| `/bank list [стр]` | весь прайс-лист страницами |
| `/bank info` | эмиссия, лимит, казна, оборот |
| `/seco give\|take\|set <ник> <сумма>` | админская корректировка счетов |
| `/seco treasury [add\|take <сумма>]` | казна сезона |
| `/seco market reset [предмет]` | сбросить насыщение курса |
| `/seco reload \| info \| export` | перезагрузка конфига, сводка, выгрузка JSON |

## Настройка курса

```yaml
prices:
  "minecraft:diamond": { name: "Алмаз", base: 8.0, quota: 96 }
  "minecraft:netherite_ingot": { name: "Незеритовый слиток", base: 260.0, quota: 8, min: 0.4 }
```

- `base` — базовая цена за штуку при нулевом насыщении;
- `quota` — сколько штук роняют цену вдвое;
- `min` — персональный пол: ниже этой доли цена не падает (глобальный — `bank.price.min-factor`).

Цены собраны так, чтобы не было крафт-арбитража: слиток дороже руды, но слабее,
чем 1:1 по переплавке; золотое яблоко дешевле 8 слитков; хлеб дешевле 3 пшеницы;
уголь = древесный уголь.

```
  config.yml

  market.json            # насыщение курса и суточная эмиссия

  web/economy.json
```

Запись атомарная (`.tmp` + `Files.move`), автосейв каждые 120 с и на `onDisable`.

## Сборка

```bash
gradle wrapper --gradle-version 8.12.1   # если нет ./gradlew
./gradlew build
# build/libs/SepiolEconomy-0.1.1.jar
```

Любой push в GitHub собирает jar через Actions (артефакт `SepiolEconomy-jar`),
тег `v*` создаёт release с jar.

## Порядок загрузки

`softdepend: [Vault, VaultUnlocked, SepiolCore, SepiolSkins, LuckPerms, AuthMe]` — плагин
работает и без них, но если Vault есть — регистрируется провайдером экономики.
