# Клиент DeltaDotNet

`DeltaDotNet.exe` — WPF-приложение в стилистике DELTARUNE: чёрный фон, белые рамки 3px,
моноширинный шрифт, жёлтый акцент, пункты меню с `*`, инверсия кнопок при наведении.
Окно резиновое (минимум 760×520), всё содержимое в скроллах — ничего не обрезается.

## 1. Вход

1. В поле **Server** введите адрес своего сервера, например `http://1.2.3.4:8080`
   или `https://ddn.example.com`.
2. **Register** — создать аккаунт, **Login** — войти.
3. Галочка **Stay signed in** сохраняет токен в `%AppData%\DeltaDotNet\settings.json`,
   следующий запуск входит автоматически.

## 2. Лобби

### Создание

- **Name** — название.
- **Players** — 2, 3 или 4 игрока (тот самый выбор количества).
- **Open / Closed**:
  - `Open` — видно всем в списке, вход свободный;
  - `Closed + Password` — вход по паролю;
  - `Closed + Allow list` — вход только тем никам, кого вы перечислили через запятую.
- **Quality** — пресет трансляции для всего лобби.

### Вход

- **Refresh** → выбрать в списке → **Join selected**.
- Или **Join by code**, если лобби закрытое (код — 6 символов, хост видит его в комнате).

### Комната лобби

| Кнопка | Кому | Что делает |
|--------|------|-----------|
| **START GAME** | хост | Запускает трансляцию и переводит всех в игровой экран |
| **READY** | гость | Отметка готовности |
| **Kick / Ban / Unban** | хост | Выгнать или забанить игрока в этом лобби |
| **CLOSE LOBBY** | хост | Удаляет лобби совсем и возвращает всех в список |
| **Leave** | все | Выйти из лобби (хостство передаётся следующему) |

Справа — чат лобби (Enter отправляет).

## 3. Игровой экран

**Хост:**
- Запустите игру с модом ДО нажатия START GAME.
- Клиент захватывает окно игры и шлёт JPEG-кадры на сервер.
- Кнопка **Focus game window** переводит фокус на игру — без этого игра не примет клавиши.
- Клавиши гостей приходят по WebSocket и нажимаются через `SendInput` со скан-кодами.
- **STOP GAME** останавливает трансляцию и возвращает всех в лобби.

**Гость:**
- Видит картинку хоста, жмёт свои клавиши — они улетают на сервер и дальше хосту.
- Галочка **Capture my keyboard** временно отключает перехват (например чтобы пописать в чат).
- Окно с трансляцией должно быть активным, иначе нажатия не ловятся.

## 4. Управление по умолчанию

| Действие | Игрок 1 | Игрок 2 | Игрок 3 | Игрок 4 |
|----------|---------|---------|---------|---------|
| Вверх / вниз / влево / вправо | `W` `S` `A` `D` | стрелки | `I` `K` `J` `L` | `Num8` `Num5` `Num4` `Num6` |
| Подтвердить (Confirm) | `Z` | `Enter` | `U` | `Num0` |
| Отмена (Cancel) | `X` | `Right Ctrl` | `O` | `Num.` |
| Меню | `C` | `C` | `Y` | `Num+` |
| Пауза | `P` | `P` | `P` | `P` |
| Ctrl | `Left Ctrl` | `Right Ctrl` | `Left Ctrl` | `Right Ctrl` |
| Shift левый / правый | `LShift` / `RShift` | `LShift` / `RShift` | `LShift` / `RShift` | `LShift` / `RShift` |

Всё переназначается в **Settings → Controls**. Там два слоя:

- **My keyboard (what I press)** — какие клавиши жмёт конкретный игрок у себя.
- **Game keys (what the host injects)** — какие клавиши хост жмёт в игре за этого игрока
  (здесь должны стоять клавиши, которые понимает ваш мод).

Нажмите кнопку рядом с действием и нажмите нужную клавишу; `Esc` очищает бинд. **SAVE** сохраняет.

## 5. Настройки

| Вкладка | Что там |
|---------|---------|
| **Quality** | Пресеты Potato / Low / Medium / High / Ultra + ручные ползунки fps, масштаб, качество JPEG, показ статистики |
| **Controls** | Переназначение клавиш для всех 4 слотов |
| **Capture** | Что транслирует хост: окно игры (по части заголовка, по умолчанию `DELTARUNE`) или весь экран; список открытых окон |
| **Themes** | Список `.ddntheme`, импорт, применение, возврат к встроенной, фоновая музыка и громкость |
| **Account** | Адрес сервера, автовход, инфо об аккаунте |

### Пресеты качества

| Пресет | FPS | Масштаб | JPEG | Примерный трафик хоста |
|--------|-----|---------|------|--------------------------|
| Potato | 10 | 40% | 30 | ~0.3 Мбит/с |
| Low | 20 | 55% | 45 | ~1 Мбит/с |
| Medium | 30 | 75% | 60 | ~3 Мбит/с |
| High | 45 | 90% | 75 | ~7 Мбит/с |
| Ultra | 60 | 100% | 90 | ~15 Мбит/с |

Цифры умножаются на число гостей: при 4 игроках хост отдаёт в 3 раза больше.

## 6. Где что хранится

```
%AppData%\DeltaDotNet\settings.json   — настройки, бинды, токен
%AppData%\DeltaDotNet\themes\        — установленные .ddntheme
%AppData%\DeltaDotNet\cache\         — распакованные ресурсы тем
```

## 7. Если что-то не работает

| Проблема | Решение |
|----------|----------|
| Чёрный экран у гостей | У хоста не найдено окно: Settings → Capture → выберите окно из списка |
| Клавиши гостя не работают в игре | У хоста не сфокусировано окно игры — нажмите **Focus game window** |
| Игра игнорирует ввод | Запустите клиент от имени администратора (если игра запущена с повышенными правами) |
| Лаги / рывки | Понизьте пресет качества или fps |
| Слетела авторизация после рестарта сервера | Не задан `DDN_SECRET` на сервере |
