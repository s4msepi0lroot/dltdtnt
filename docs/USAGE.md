# Использование CoopStream

## 0. Что нужно

- Сервер с Node.js 18+ или Docker (выбирайте локацию поближе к игрокам — это главный фактор задержки).
- Два ПК на Windows 10/11 (x64).
- Игра с локальным коопом установлена только у хоста.

## 1. Сборка в GitHub Actions

1. Создайте репозиторий и залейте туда содержимое архива:
   ```bash
   git init
   git add .
   git commit -m "CoopStream"
   git branch -M main
   git remote add origin https://github.com/<вы>/<репо>.git
   git push -u origin main
   ```
2. Откройте вкладку **Actions**. Сборка `build` запустится автоматически (или жмите **Run workflow**).
3. После зелёной галочки в разделе **Artifacts** будут:
   - `CoopStream-client-win-x64` — самодостаточный `CoopStream.exe` (.NET ставить не нужно);
   - `CoopStream-server` — папка сервера для деплоя.
4. Если поставить тег `v1.0.0` и запушить его, архивы автоматически прикрепятся к GitHub Release:
   ```bash
   git tag v1.0.0 && git push origin v1.0.0
   ```

Локальная сборка (если есть .NET 8 SDK):
```powershell
dotnet publish client/CoopStream.Client/CoopStream.Client.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -o out
```

## 2. Запуск сервера

Минимум:
```bash
cd server
export AUTH_SECRET=$(node -e "console.log(require('crypto').randomBytes(32).toString('hex'))")
node src/index.js
# -> CoopStream relay слушает :8080 (ws путь /ws)
```

Проверка здоровья: `curl http://адрес:8080/health` → `{"ok":true,...}`.

Все варианты размещения (Docker, Railway, Fly.io, VPS + nginx + HTTPS) — в [DEPLOY.md](DEPLOY.md).

## 3. Авторизация

1. Запустите `CoopStream.exe`.
2. В поле **Адрес** введите `ws://ваш-адрес:8080/ws`
   (или `wss://домен/ws`, если поставили HTTPS-прокси).
3. Логин: 3–24 символа `A-Z a-z 0-9 _ . -`. Пароль: от 6 символов.
4. Нажмите **Регистрация** (один раз), дальше — **Войти**.
5. Токен сохраняется в `%APPDATA%\CoopStream\config.json`, следующий запуск входит автоматически (токен живёт 7 дней).

Когда оба аккаунта созданы, выставьте на сервере `ALLOW_REGISTER=0` — чужие больше не зарегистрируются.

## 4. Лобби

**Хост** (тот, у кого запущена игра):
1. Введите название лобби.
2. Выберите **свою** роль: «Я — игрок 1 (WASD…)» или «Я — игрок 2 (стрелки…)».
   Гость автоматически получает противоположную роль.
3. **Создать лобби** → в журнале появится **КОД** из 6 символов (например `K7M2QD`).

**Гость**:
1. Нажмите **Обновить список** и дважды кликните по лобби,
   либо введите код и нажмите **Войти по коду**.

**Хост** видит «К вам присоединился …» и жмёт **Начать игру**.

## 5. Сессия

### Окно хоста

| Элемент | Что делает |
|---|---|
| **Источник** | «Весь экран» или конкретное окно игры. Кнопка `↻` обновляет список |
| **FPS** | частота кадров (старт с 20; больше = плавнее и тяжелее) |
| **Качество** | JPEG 20–95 (55 — хороший компромисс) |
| **Ширина** | кадр уменьшается до этой ширины перед отправкой |
| **Пауза ввода (F8)** | временно игнорировать клавиши гостя (набрать текст, полезть в меню) |

Хост после старта переключается на окно игры и играет как обычно.
Окно CoopStream остаётся поверх (TopMost) — можно сдвинуть в угол.

### Окно гостя

Показывает трансляцию. Внизу — статус: кадры, трафик, задержка, ваши клавиши.
**Важно:** окно должно быть в фокусе, иначе нажатия не уйдут.
При потере фокуса все клавиши автоматически отпускаются, чтобы персонаж не «залип».

### Раскладка

- **P1**: `W` `A` `S` `D`, `Z`, `X`, `P`, `C`, оба `Ctrl`, оба `Shift`.
- **P2**: `↑` `↓` `←` `→`, `Enter` (основной и на нампаде), `C`, оба `Ctrl`, оба `Shift`.

Любая другая клавиша у гостя просто игнорируется.
Левый и правый Shift/Ctrl различаются и передаются по отдельности.

## 6. Завершение

- Закройте окно сессии — трансляция остановится, все клавиши отпустятся.
- **Покинуть лобби** в главном окне распускает лобби (если вышел хост) или освобождает слот гостя.

## 7. Настройки клиента

Файл `%APPDATA%\CoopStream\config.json`:

```json
{
  "serverUrl": "ws://127.0.0.1:8080/ws",
  "login": "player1",
  "token": "...",
  "fps": 20,
  "jpegQuality": 55,
  "maxWidth": 1280,
  "hostRole": "P1"
}
```

Удалите файл, чтобы сбросить всё к заводским значениям и выйти из аккаунта.

## 8. Советы по качеству

| Ситуация | Что сделать |
|---|---|
| Рвёт видео | снизьте ширину до 960 и качество до 40 |
| Высокая задержка | перенесите сервер ближе к игрокам, уменьшите FPS |
| Нужна точность ввода | ввод и видео независимы: даже при низком FPS нажатия идут мгновенно |
| Игра теряет фокус | включите в игре оконный/borderless режим |
