# 07. Админка

## Кто имеет доступ

Ровно один аккаунт — тот, чей логин равен `DDN_ADMIN_USERNAME`
(по умолчанию **`s4msepi0l`**). Сравнение без учёта регистра.

Проверка живёт на **сервере**: любое сообщение `admin.*` от чужого аккаунта
отвергается с `error: "admin only"`. Кнопка **ADMIN** в шапке клиента просто
прячется у остальных — но даже если кто-то пересоберёт клиент, сервер его не пустит.

Сменить владельца: перезапустите сервер с другим `DDN_ADMIN_USERNAME`.

## Экран

Слева — список всех аккаунтов с поиском и отметкой «● online».
Справа — статистика сервера, глобальные кнопки и список живых лобби.

## Что можно делать с игроком

| Кнопка | Команда | Описание |
|---|---|---|
| `RAINBOW` | `admin.setRainbow` | **переливающийся ник**. Виден всем: в лобби, в чате, в списке игроков |
| `COLOR` | `admin.setNameColor` | фиксированный цвет ника `#RRGGBB` |
| `BADGE` | `admin.setBadge` | текстовый бейдж до 12 символов, например `OWNER` |
| `RANK` | `admin.setRank` | `player` / `vip` / `moderator` / `admin` |
| `PASSWORD` | `admin.resetPassword` | сброс пароля |
| `BAN` / `UNBAN` | `admin.globalBan` | глобальный бан на весь сервер |
| `DELETE` | `admin.deleteUser` | удалить аккаунт навсегда |

Изменения прилетают игроку сразу сообщением `profile.updated` — перезаходить не нужно.

## Глобальные возможности

| Кнопка | Команда | Описание |
|---|---|---|
| `BROADCAST` | `admin.broadcast` | сообщение всем онлайн-игрокам |
| `SET MOTD` | `admin.setMotd` | текст на экране списка лобби |
| `MAINTENANCE ON/OFF` | `admin.setMaintenance` | режим обслуживания: пускает только вас |
| `REFRESH STATS` | `admin.stats` | аккаунты, онлайн, лобби, uptime, память |
| `CLOSE THIS LOBBY` | `admin.killLobby` | закрыть любое чужое лобби |

## Права хоста (не админа)

В своём лобби любой хост может:

- `KICK` — выгнать (можно вернуться);
- `BAN` — выгнать и запретить вход в это лобби, `UNBAN` — снять;
- `SLOTS` — пересадить игрока в другой слот;
- `RENAME` — переименовать лобби;
- `ACCESS` — переключить open/closed, задать пароль или список логинов;
- `CLOSE THE LOBBY` — удалить лобби, всех выкидывает в список.

## Закрытые лобби

Два независимых фильтра, работают вместе или по отдельности:

1. **Пароль** — кто знает, тот зайдёт.
2. **Список логинов (allowList)** — зайдут только перечисленные.

Закрытые лобби не показываются в общем списке — только по ID.

## Замечание про безопасность

Гость фактически шлёт нажатия на компьютер хоста. Сервер пропускает только
десять разрешённых действий и только во время активной игры, а клиент хоста
превращает их только в клавиши из таблицы слотов. Но если вы свернёте игру,
эти клавиши уйдут в то окно, что сейчас активно. Правило простое: играете —
держите игру в фокусе, а в лобби пускайте знакомых.
