# Админка DeltaDotNet

## Доступ

Кнопка **Admin** в шапке клиента появляется только у владельца — аккаунта с ником
**`s4msepi0l`** (меняется переменной `DDN_OWNER` на сервере). Проверка делается **на сервере**:
даже если кто-то подправит клиент, админ-эндпоинты ответят `403`.

Просто зарегистрируйте аккаунт `s4msepi0l` — сервер сам выдаст ему роль владельца,
бейдж `OWNER` и радужный ник. Забанить или удалить владельца нельзя.

## Вкладка Users

- Поиск по нику, список с ролью, бейджем и пометками `RAINBOW` / `BANNED`.
- **Rainbow nickname** — тот самый переливающийся ник: имя такого игрока плавно
  переливается цветами радуги в шапке, списке участников лобби и в чате у всех игроков.
- **Static name color** — однотонный цвет ника (`#RRGGBB`), если радуга не нужна.
- **Badge** — метка рядом с ником: `VIP`, `MOD`, `DEV`, что угодно.
- **Role** — `user` / `admin` (админ может закрывать чужие лобби, но не видит админку владельца).
- **Rename user** — смена ника.
- **Ban account** — глобальный бан с причиной: человека выкидывает из сети сразу (`forceLogout`).
- **Unban / Delete account**.

## Вкладка Lobbies

Список всех лобби, включая закрытые и скрытые из обычного списка,
и кнопка принудительного закрытия любого из них.

## Вкладка Server

- **Broadcast** — сообщение всем онлайн (показывается в статус-баре и чате лобби).
- **MOTD** — сообщение дня, показывается всем при входе.
- **Статистика** — онлайн, число лобби и идущих партий, всего аккаунтов, аптайм,
  список кто сейчас в сети.

## Права хоста (не путать с админкой)

Любой игрок, создавший лобби, внутри своего лобби может: кикать, банить и разбанивать,
менять качество, запускать и останавливать игру, а также **CLOSE LOBBY** — удалить лобби
целиком и вернуться в список. Если хост просто вышел, хостство переходит следующему
игроку; если лобби опустело — сервер удаляет его сам.
