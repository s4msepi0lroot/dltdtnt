# Протокол DeltaDotNet

Подключение: `ws(s)://<сервер>/ws`. Первым сообщением обязательно `auth`.
Текстовые кадры — JSON, бинарные — видео.

## Клиент → сервер

| `type` | Поля | Кто может |
|--------|------|------------|
| `auth` | `token` | все |
| `join` | `lobbyId`, `password?` | все |
| `leave` | — | участник |
| `ready` | `ready` | участник |
| `quality` | `quality {fps, scale, jpegQuality}` | хост |
| `start` | — | хост |
| `stop` | — | хост |
| `input` | `action`, `down` | гость |
| `chat` | `text` | участник |
| `kick` / `ban` / `unban` | `userId` | хост |
| `close` | — | хост |
| `ping` | — | все |

## Сервер → клиент

| `type` | Описание |
|--------|----------|
| `authed` | Успешная авторизация, отдаёт `user` и `motd` |
| `joined` | Вы вошли в лобби: `lobby`, `slot`, `isHost` |
| `lobby` | Обновлённое состояние лобби (состав, готовность, баны, качество) |
| `started` / `stopped` | Игра началась / закончилась |
| `input` | Только хосту: `slot`, `action`, `down` |
| `chat` | Сообщение чата (с цветом/радугой автора) |
| `announce` | Системное сообщение / админ-броадкаст |
| `kicked` | Вас выгнали: `banned`, `reason` |
| `lobbyClosed` | Лобби удалено |
| `forceLogout` | Аккаунт забанен/удалён админом |
| `error` | Ошибка: `message` |
| `pong` | Ответ на `ping` |

## Бинарный видеокадр

Заголовок 13 байт, дальше — JPEG:

```
байт 0        : 1  (тип = видео)
байты 1..4   : seq     (uint32 big-endian)
байты 5..8   : width   (uint32 big-endian)
байты 9..12  : height  (uint32 big-endian)
байты 13..   : JPEG
```

Сервер не декодирует картинку, а просто пересылает буфер всем гостям лобби.
Если `socket.bufferedAmount > 4 МБ`, кадр для этого клиента пропускается (анти‑затор).

## Список действий (`action`)

`up`, `down`, `left`, `right`, `confirm`, `cancel`, `menu`, `pause`, `ctrl`, `shiftL`, `shiftR`

Действия логические: гость шлёт не код клавиши, а действие; хост превращает его в реальную
клавишу по своей карте «Game keys» для соответствующего слота. Поэтому каждый игрок может
жать удобные ему кнопки, а в игре всё равно нажмутся те, которые понимает мод.

## Жизненный цикл партии

```
хост: auth → (HTTP POST /api/lobbies) → joined
гость: auth → join → joined → ready
хост: start  ──▶ всем started
хост: бинарные кадры ──▶ гостям
гость: input ──▶ сервер ──▶ хост ──▶ SendInput в игру
хост: stop или close
```
